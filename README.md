# Reserva de Cine - UEA
**Estudiante:** Emily Guano

**Objetivo:** Crear un sistema básico de reserva de asientos para una sala de cine de 3 filas x 4 columnas usando una matriz en Python.

**Descripción:** El programa inicializa una sala con ceros (0 = libre). Solicita al usuario la fila y columna, marca ese asiento como reservado con un 1, y muestra el estado completo de la sala.

**Cómo ejecutarlo:**
1. Tener Python instalado
2. Ejecutar en consola: python reserva_cine.py
3. Ingresar fila (0 a 2) y columna (0 a 3) cuando lo pida
